# 时光舱 · Countdown Studio

一个有点浪漫的个人倒计时面板。Go 提供 API，SQLite 保存数据，Vue 3 提供界面；生产前端嵌入 Go 可执行文件，不需要单独部署 Node 服务。

## 有什么

- **日期倒计时**：旅行、生日、项目截止日期；过期后显示「期待已抵达」。
- **纪念日正计时**：从一个日期开始累计天数，并实时显示时分秒。
- **短时计时**：自定义时长，支持暂停、恢复、重新开始；刷新后仍保留状态。
- **重复日期**：每天、每周、每年重复；按保存时的 IANA 时区计算，兼顾夏令时。2 月 29 日在平年按 2 月 28 日处理。
- **二十四种时钟外观**：翻页时钟、发光数字、时光光环、极简进度、霓虹数码管、机械仪表、点阵时钟、进度阶梯、时间票根、经典指针、流沙沙漏、星际轨道、极客终端、手账便签、水波时光、撕页日历、机械滚轮、磁带记忆、拍立得时光、二进制灯阵、时光雷达、竹简时光、棱镜光谱、星图时钟。新增/编辑时可以实时预览，首页精选卡片、普通卡片、列表和专注视图都会使用保存的样式。
- 顶部精选只展示「生活」和「纪念日」两类示例记录，按置顶优先、到期时间最近选择；不选普通记录、工作、专注或已到期记录。清空示例后显示默认欢迎画面，不自动补建数据。
- **五种配色**：暮光紫、落日粉、海盐蓝、暖杏橙、薄荷绿。
- **十二种页面氛围**：自在山野、日落心动、蔚蓝远行、森林专注、星河漫游、极光之夜、赛博霓虹、落日沙丘、雨夜听风、樱花来信、月下竹影、雪山日出。背景使用本地 SVG 绘制，包含流星、极光、霓虹、雨、雪、花瓣等动效。
- **随时间变化的日月**：自然场景中，太阳沿本地时间 06:00–18:00 的示意弧线升起、移动、落下；夜间换为月亮，天空和星光随晨昼暮夜变化。星河、极光、霓虹、雨夜、竹影主题保留夜景，天体同样随时间移动。首页与大屏共用服务器校正后的浏览器本地时钟；轨迹适配手机裁切和全屏尺寸。此功能不读取定位，不计算真实天文日出日落。
- 七种独立动效（静静欣赏、微风流动、流星掠过、萤火浮光、雨落窗边、雪花轻舞、樱花飞舞）可与页面氛围组合，首页和大屏同步；页面氛围、深浅模式、动效选择在当前浏览器中记忆；到期时有短暂庆祝彩屑，关闭动效或系统要求减少动态效果时不显示。
- 分类、置顶、关键词搜索、状态筛选、排序、卡片/列表布局。
- 分类选择器展开时显示全部分类，并支持新建分类；分类和重复方式使用统一的自定义菜单，支持方向键、Home/End、Enter、Escape 与键盘焦点操作。
- 专注视图与浏览器全屏、浅色/深色模式、响应式移动端界面。
- **沉浸大屏**：切换当前时钟与自己的倒计时，选择氛围和二十四种时钟样式；当前时钟还保留经典大数字模式，可进入系统全屏。
- **可选白噪音**：大屏内手动播放雨声、海浪和低频棕噪音，支持音量调节，关闭大屏即停止。使用 Web Audio 合成，不加载外部音频，不自动播放。
- **日历视图**：按月浏览时刻，切换月份、回到今天、选择某天查看列表，再打开专注视图。日历按本机时区显示；重复项显示后端计算出的下一次日期。
- **一键专注**：直接创建 5、15、25、45 分钟的 SQLite 持久化计时，并打开专注视图。
- 页面打开时的到期提示，可手动开启声音；不是后台通知服务，页面关闭后不会提醒。
- JSON 导出备份和原子导入；导入创建新记录，失败不会写入一半。

首次创建数据库会添加 6 个带「示例」标记的时刻，可以在界面一键清空；清空后不会自动重建。编辑过的示例会成为自己的记录。

## 启动

需要 **Go 1.25+、Node.js 22.12+、npm**。

```sh
cd ~/work/repo-set/tools/countdown-studio
make run
```

打开 **http://127.0.0.1:8080**。默认数据库为 `data/countdown.db`。

也可以分步构建：

```sh
cd web
npm ci
npm run build
cd ..
CGO_ENABLED=0 go build -trimpath -o bin/countdown-studio .
./bin/countdown-studio -addr 127.0.0.1:8080 -db data/countdown.db
```

首次启动不添加示例：

```sh
./bin/countdown-studio -demo=false -db data/clean.db
```

`-demo=false` 仅控制新数据库初始化，不会删除已有示例。前端资源在编译时嵌入，修改前端后需重新构建 Go 二进制。
SQLite 使用纯 Go 驱动，可关闭 CGO；数据库启用 WAL 和 busy timeout。接口最多保存 500 项；备份文件最大 2 MB。

这是个人或可信网络中的共享工具，不包含登录和用户隔离。默认只监听本机；需要远程使用时自行配置认证代理和 HTTPS，再使用 `-addr 0.0.0.0:8080`。

## 开发

先执行一次 `make build`，然后使用两个终端：

```sh
# 终端 1：后端 8080
make dev-api

# 终端 2：Vite 热更新 5173，自动代理 /api 到 8080
make dev-web
```

日期输入以浏览器所在时区解释，后端保存绝对时间和时区；编辑未修改日期时保留原日期和时区。
界面会根据服务器时间修正本机时钟偏差。重复项在下次到期后自动计算下一次日期；纪念日不重复时则持续正计时。
短时计时的暂停剩余秒数保存于数据库；运行中的计时不会因服务重启而重新开始。

## 验证

```sh
make test

# 浏览器端到端测试；使用 Playwright 的 Chromium
cd web && npx playwright install chromium && cd ..
make test-e2e

# macOS 也可使用已经安装的 Chrome，无需下载浏览器
PLAYWRIGHT_CHROMIUM_EXECUTABLE="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" make test-e2e
```

Go 测试覆盖 SQLite 跨连接持久化、CRUD、暂停/恢复、时区/夏令时/闰日、原子导入、非法输入、跨站写保护与示例清理。
前端测试覆盖倒计时边界、纪念日正计时、暂停状态、重复日期和本地日期转换。
浏览器测试使用独立测试数据库，覆盖新增、编辑、刷新、暂停恢复、备份导入导出、12 套氛围、动效偏好、到期庆祝、日历选日、专注视图、沉浸大屏、白噪音播放/停止/音量、一键专注、深色模式、删除确认、移动端布局；截图保存在 `web/test-results/`。

## API

| 方法 | 路径 | 功能 |
| --- | --- | --- |
| GET | `/api/health` | 数据库健康检查 |
| GET | `/api/events` | 读取全部时刻和服务器时间 |
| POST | `/api/events` | 新增 |
| PUT | `/api/events/{id}` | 编辑 |
| DELETE | `/api/events/{id}` | 删除 |
| POST | `/api/events/{id}/action` | `pin`、`pause`、`resume`、`restart` |
| POST | `/api/events/import` | 导入 `{ "version": 1, "events": [...] }` |
| DELETE | `/api/examples` | 清空仍标记为示例的记录 |

写入请求使用 `Content-Type: application/json`。后端校验字段、日期、时区和大小，并拒绝不同源的浏览器写入。所有数据库值都通过参数绑定处理。

## 数据与备份

优先使用界面的 JSON 导出。文件级备份时应先停止服务，再复制 `.db`；运行中直接复制单个 `.db` 会遗漏尚在 WAL 中的数据。
不要把个人数据库提交到 Git。`data/`、二进制、前端依赖和构建结果已加入忽略规则。

## 目录

```text
main.go / main_test.go     Go 服务、SQLite 与测试
go.mod / go.sum           后端依赖
web/src/                  Vue 界面、时钟组件和日期逻辑
web/e2e/                  浏览器端到端验证
web/dist/                 构建输出，编译时嵌入 Go
data/                     运行时 SQLite 数据
bin/                      本地构建的可执行文件
```

顶部精选优先展示置顶的生活、纪念日或节日（含正计时纪念日）；没有符合条件的置顶项时使用生活、纪念日示例。多个置顶项按距离目标时间排序；短时计时、已到期倒计时和暂停项不进入精选。

节日倒计时收录 20 个精选主题（12 个中国节日、8 个国外大型节庆），支持分类和搜索，保存各自的配色和 SVG 装饰，卡片、实时预览、专注视图、大屏和日历共享节日主题。新建时可选择“节日倒计时”或“节日将至”。选择预设会填入标题、文案、下一次日期和建议重复方式；标题和日期均可修改。农历日期内置香港天文台 2026–2035 年官方对照表，运行时无需联网，超出范围需手动填写日期，农历节日及清明等浮动日期节日以单次日期保存，每年重新选择预设更新，避免按公历日期重复。节日也可置顶进入顶部精选。

农历日期来源：[香港天文台公历与农历对照表](https://www.hko.gov.hk/en/gts/time/conversion.htm)，使用其官方文字历表数据，2027 年示例：[官方数据](https://data.weather.gov.hk/weatherAPI/hko_data/calendar/nongli_calendar_2027.csv)。

节日收录偏好：精简为 20 个主题。中国节日保留春节、元旦、元宵、清明、端午、七夕、中秋、重阳、腊八、除夕、国庆、劳动节；国外仅保留圣诞节、万圣节、慕尼黑啤酒节、美国感恩节、狂欢节、墨西哥亡灵节、潘普洛纳奔牛节和京都祇园祭。后续不添加非洲、东南亚、南亚、中东阿拉伯地区的节庆，也不扩充零散的小众国外节日。

扩充节日按中国／世界分类并支持搜索。感恩节按美国 11 月第四个星期四计算；狂欢节使用狂欢周二；慕尼黑啤酒节按传统开幕规则预填并允许按主办方公告调整；祇园祭默认 7 月 17 日前祭巡行；奔牛节默认 7 月 6 日节庆开幕。浮动日期节日以单次日期保存，每年重新选择预设更新，防止固定公历重复造成日期偏差。
日期核对来源：[美国海军天文台](https://aa.usno.navy.mil/faq/holidays)、[慕尼黑啤酒节官网](https://www.oktoberfest.de/en/information/oktoberfest-opening-times/opening-hours-munich-oktoberfest)、[新奥尔良官方旅游局](https://www.neworleans.com/events/holidays-seasonal/mardi-gras/the-ultimate-mardi-gras-guide/)、[日本国家旅游局](https://faq.japan-travel.jnto.go.jp/en/spot/83/)。
